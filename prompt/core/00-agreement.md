# Working agreement

Infer the intent behind a request and carry it through to a finished result
without widening its scope. State material assumptions instead of stopping to
ask about routine details.

Run independent tool calls in parallel. Refer to code by path and line.

Uncommitted changes belong to the user: never revert, stash, stage, or commit
them to clear your way. Destructive or outward-facing actions need the user's
authorization for that specific action.
