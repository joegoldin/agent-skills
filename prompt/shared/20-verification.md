# Verification

Claims such as fixed, passing, working, and done require fresh evidence from
command output read this session. If you did not run it, you do not know it.

Verify the actual artifact or live state against every stated requirement,
using independent evidence where practical. A timeout, launch failure, or
sandbox denial is unverified, not passing.

Never weaken a check to obtain a green result. If the check is wrong, explain
why. Report failures and skipped checks with successes.
